# migrate-mcp v0.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, validate, publish, and independently verify `migrate-mcp@0.0.1`, a local stdio MCP server that detects, inspects, reviews, explains, and safely generates migrations for Alembic, golang-migrate, TypeORM, Sequelize, and Prisma without applying database changes.

**Architecture:** MCP handlers validate inputs and call framework-neutral workflow services. Services select narrow framework adapters, while pure analyzers inspect migration files and a single constrained process runner owns all subprocess execution. Framework adapters expose capability evidence explicitly so unsupported drift or generation paths cannot be mistaken for successful verification.

**Tech Stack:** Node.js 22+, TypeScript 7, ESM, `@modelcontextprotocol/server` 2.x, Zod 4, YAML 2, smol-toml 1, Vitest 5, ESLint, Prettier, tsdown, publint, npm.

**Spec:** `docs/superpowers/specs/2026-09-23-migrate-mcp-design.md`

## Global Constraints

- Package, repository, and binary name: `migrate-mcp`.
- Initial version: `0.0.1`.
- Supported frameworks: Alembic, golang-migrate, TypeORM, Sequelize, and Prisma.
- The server is local and stdio-only; stdout carries MCP JSON-RPC only.
- No MCP tool may apply, revert, reset, drop, repair, stamp, resolve, force, or otherwise mutate a database.
- Migration generation requires `approved: true`, a repository-contained path, a clean preflight, and a non-production target.
- Framework CLIs and database drivers are not installed or bundled by this package.
- Unsupported or incomplete framework evidence must be returned explicitly and never guessed.
- Child processes use argument arrays with `shell: false`, bounded output, timeout, cancellation, redaction, and repository-scoped working directories.
- Database inspection documentation must recommend read-only credentials and state that the tool is not a sandbox.
- Use Conventional Commits, author `royalpinto007 <royalpinto007@gmail.com>`, and never add Co-Authored-By trailers.
- Release only after the packed and published packages pass clean-consumer MCP and API smoke tests.

## Review Focus

- A repository containing both Prisma and TypeORM must return an ambiguous-framework error for framework-specific tools until the caller selects one; Task 3 adds this test.
- A symlinked migration directory escaping the repository must be rejected before any process starts; Task 2 adds this test.
- A framework process that writes an unexpected file outside its declared migration directory must fail generation and report the path; Task 10 adds this test.
- Output containing percent-encoded credentials, query-string tokens, or split-line secrets must be redacted in MCP text and structured content; Task 2 adds this test.
- Prisma prerelease or unknown major versions must report unsupported capability details instead of falling through to the nearest command family; Task 9 adds this test.
